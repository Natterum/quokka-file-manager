## [0.2.0] — 2026-11-21

### Добавлено

- Работа с серверами SFTP, FTP и FTPS (явный TLS): «Сервис → Подключение к серверу…» (Ctrl+K) открывает папку сервера во вкладке панели, как обычную. Сохранённые подключения, вход по паролю или файлу ключа (без пароля — ключи из `~/.ssh`), подтверждение отпечатка ключа сервера с записью в `known_hosts`. Пароли можно запомнить — они хранятся в диспетчере учётных данных Windows, а не в файле настроек. Копирование, перемещение и удаление через очередь операций: скачивание, загрузка на сервер и между серверами. Для SFTP — «SSH-терминал» (Ctrl+Shift+P) в PuTTY или встроенном в Windows `ssh.exe`.
- «Свойства» в контекстном меню (Ctrl+Alt+Enter, «Файл → Свойства»): стандартное окно свойств Windows для файла, папки или диска; для нескольких отмеченных — одно общее окно, как в Проводнике. «Свойства папки» в меню пустой области открывают свойства текущей папки.
- Проверка и установка обновлений: раз в сутки при запуске и по «Справка → Проверить обновления…» Quokka спрашивает GitHub Releases о новой версии и показывает список изменений. «Обновить и перезапустить» скачивает пакет, сверяет SHA-256, устанавливает и перезапускает программу с теми же вкладками: установленная через MSI — новым MSI, портативная — заменой quokka.exe. Версию можно пропустить; проверка отключается в «Настройки → Вид и файлы → Обновления».
- Установщик MSI для x64 и x86 (WiX): Program Files, ярлык в меню «Пуск», обновление поверх прежней версии в ту же папку. Выпуски на GitHub содержат MSI рядом с ZIP, а CI готовит манифесты winget и при наличии секрета `WINGET_TOKEN` отправляет их в winget-pkgs.
- Массовая конвертация изображений (Ctrl+Shift+E, контекстное меню, «Файл»): JPEG, PNG, WebP (с потерями и без), AVIF, BMP, TIFF, GIF, ICO, TGA, QOI. Качество 1–100 для JPEG/WebP/AVIF, степень сжатия для PNG. По умолчанию результат сохраняется рядом с исходным файлом, к имени добавляется `_conv` (меняется в диалоге): `фото.png` → `фото_conv.webp`; при повторном запуске на той же папке прежние результаты не конвертируются заново. Можно сохранить в отдельную папку — тогда структура подпапок сохраняется. Папки обрабатываются рекурсивно, файлы конвертируются параллельно через очередь операций. Ориентация по EXIF применяется, прозрачность в JPEG заливается белым, дата изменения сохраняется. В диалоге — оценка итогового размера по нескольким файлам выборки, пересчитывается при смене формата и качества. Повреждённый файл не останавливает пакет.
- Отдельное модальное окно настройки колонок: изменение порядка перетаскиванием мышью с указателем места вставки, флажки видимости, «Применить», «Отмена» и сброс к стандартному составу. Добавлены дата создания, дата доступа, расширение и атрибуты файла, сортировка по новым колонкам. Состав, порядок и ширина сохраняются отдельно для каждой панели; прежние настройки мигрируют автоматически.
- ZIP как папка: Enter открывает архив в панели, навигация по подпапкам и история переходов, F3 показывает содержимое, F5 извлекает выбранные файлы и папки через очередь. Режим только для чтения, проверка CRC и сохранение прежнего файла назначения при ошибке или отмене.
- Просмотр фотографий через F3: PNG/JPEG/BMP/GIF/WebP/ICO, вписывание, масштабирование и прокрутка, учёт ориентации изображения. Фоновое чтение и декодирование, в том числе из ZIP.
- «Сервис → Открыть PowerShell / Terminal» (Ctrl+Shift+P) в текущей папке; внутри ZIP — в папке архива.
- Выделение и снятие выделения по маске (Ctrl+S / Ctrl+Shift+S), несколько масок через `;`, инверсия видимого выделения (Ctrl+Shift+I).
- Отмена перемещения: после F6, вырезания-вставки или перетаскивания с перемещением кнопка «Отменить» в уведомлении и Ctrl+Z возвращают файлы на прежнее место (и после отменённого или прерванного перемещения — то, что успело переместиться). Ничего не перезаписывается: если исходное место уже занято, файл пропускается.
- Английский язык интерфейса. Язык выбирается в «Настройки → Вид и файлы → Язык интерфейса» и применяется сразу, без перезапуска; при первом запуске берётся язык Windows (русский для русской системы, иначе английский). Стандартные закладки избранного, которые не переименовывались, получают названия на выбранном языке.
- Строка меню сверху окна: «Файл», «Правка», «Вид», «Переход», «Сервис», «Справка». В ней собраны все команды с подписанными сочетаниями клавиш; недоступные в текущей папке пункты неактивны, включённые режимы (две панели, скрытые файлы, очередь, регистр, regex, сортировка) отмечены галочкой.
- Окно «О программе»: открывается щелчком по логотипу или названию Quokka и из меню «Справка». Описание программы, версия и список изменений.
- Групповое переименование (Ctrl+M, пункт контекстного меню, F2 при нескольких отмеченных) с масками: `[N]`, `[E]` и их диапазоны (`[N2-5]`, `[N2,3]`, `[N-4-]`), счётчик `[C]` / `[C10+5:3]`, папка `[P]` / `[G]`, дата и время изменения `[Y-M-D]`, `[hms]`, размер `[S]`, регистр `[U]` `[L]` `[F]` `[n]`. Плюс поиск и замена (несколько замен через `|` или регулярное выражение с `$1`), смена регистра, счётчик с началом, шагом и числом цифр. Живой предпросмотр до переименования: конфликты (одинаковые имена, занятые имена, недопустимые символы, зарезервированные имена Windows) подсвечиваются, любой файл можно исключить галочкой. Обмен именами (`a ↔ b`) выполняется безопасно, при ошибке всё возвращается как было; Ctrl+Z или «Отменить» в уведомлении отменяет переименование. История масок сохраняется.
- Вкладки обеих панелей, текущая вкладка и активная панель сохраняются и открываются при следующем запуске (отключается в «Настройки → Вид и файлы»). Папка, которой больше нет, заменяется ближайшей существующей.
- Значок в области уведомлений (трей): щелчок показывает окно, правый щелчок — меню «Открыть Quokka» / «Выход».
- Настройка «Скрывать в трей при закрытии»: крестик окна прячет Quokka в трей, фоновые операции продолжаются; выход — F10 или «Выход» в меню значка.
- Настройка «Разрешить несколько окон Quokka». По умолчанию выключена: повторный запуск показывает уже открытое окно, а папка из командной строки открывается в нём новой вкладкой.
- Ctrl+C / Ctrl+X / Ctrl+V для копирования, вырезания и вставки файлов в текущую папку через системный буфер обмена Windows, включая обмен с Проводником и пункты контекстного меню. Текстовые поля сохраняют обычное поведение сочетаний.
- Анимация открытия файла двойным кликом, Enter или через меню: подсветка строки, пульс иконки и краткий индикатор «Открывается…».
- Фоновый расчёт размера выбранных папок (Alt+Enter) или всех папок панели через контекстное меню, с отменой. Размеры видны в колонке и участвуют в сортировке; недоступные объекты и ссылки отмечаются как неполный результат. Обновление списка сбрасывает расчёт.
- Перетаскивание файлов мышью (за иконку или имя): между панелями, на папку в списке, наружу — в Проводник и другие программы, и обратно из них в Quokka. Ctrl — копировать, Shift — переместить; без клавиши — перемещение в пределах диска и копирование между дисками, как в Проводнике. Рядом с курсором видно, что произойдёт; Esc отменяет.
- Поиск файлов (Alt+F7): маски с исключениями, регулярные выражения по имени, поиск текста внутри файлов (регистр, слова целиком, regex, «не содержит», UTF-16 и Windows-1251), глубина, фильтры по размеру и дате, скрытые файлы, имена внутри ZIP. Результаты появляются по ходу поиска; переход к файлу, просмотр, редактирование и «Файлы в панель». История масок и текстов сохраняется.
- F4 открывает файл во внешнем редакторе. Программа задаётся в «Настройки → Вид и файлы» (`%f` — путь к файлу); по умолчанию Блокнот. Встроенный редактор перенесён на Shift+F4.
- Отмена удаления в корзину: кнопка «Отменить» в уведомлении и Ctrl+Z возвращают файлы на прежнее место.
- Очередь операций: копирование, перемещение, удаление, корзина, архивация и распаковка выполняются по очереди в фоне, не блокируя интерфейс. Панель очереди (Ctrl+J или кнопка в верхней панели): прогресс, отмена, пауза, изменение порядка, повтор упавших задач.
- Распаковка ZIP-архивов (Alt+F6), в том числе нескольких сразу и с кириллическими именами в CP866.
- Подтверждение выхода, пока в очереди есть незавершённые операции.

### Изменено

- Переработан дизайн настройки колонок: список с цветными иконками и примерами значений, заметные флажки видимости, отдельная область живого предпросмотра, счётчик включённых колонок и компактные подсказки.
- Код разделён на слои по принципам чистой архитектуры: `quokka-domain`, `quokka-core` (сценарии и порты), `quokka-infra` (адаптеры) и интерфейс. Ядро не зависит от egui, Windows и `std::fs` и тестируется на файловой системе в памяти.
- Папки читаются в фоне: большие, сетевые и медленные папки больше не замораживают окно — пока список читается, видно «Загрузка…». Переход в недоступную сетевую папку ждёт ответа не дольше 0,4 с.
- Открытые папки обновляются сами при изменениях на диске, в том числе сделанных другими программами. После операции обновляются только вкладки с затронутыми папками; скрытые вкладки — когда их покажут.
- Значки файлов кэшируются по типу: папка с тысячами однотипных файлов загружает значок один раз.
- Список дисков читается одним вызовом ОС, а свободное место для подсказок сайдбара — в фоне, а не в каждом кадре.
- Архивация (Alt+F5) и распаковка (Alt+F6) по умолчанию кладут результат в соседнюю панель, как копирование (F5). Если там «Этот компьютер» — в текущую папку. Путь в диалоге можно изменить.

### Исправлено

- Колонки больше не скрываются при сужении панели: меняется только ширина колонки «Имя», при нехватке места доступна горизонтальная прокрутка. Длинные заголовки сокращаются с `...`, полное название доступно при наведении.
- Системная тема больше не сбрасывает стиль кнопок при запуске: заданные внутренние отступы сохраняются для светлой и тёмной темы ОС.
- Быстрые одиночные клики по разным файлам больше не запускают файл и не вызывают переход в результатах поиска: двойной клик требует двух последовательных кликов по одному элементу.
- Внутренние отступы текстовых кнопок и пунктов меню увеличены до 32 px по горизонтали и 10 px по вертикали и унифицированы, включая диалоги и поиск. Ряд кнопок в диалогах увеличен по высоте. Текст пунктов меню больше не смещается при наведении.
- Плавное изменение ширины колонок без потери мелких движений мыши и появления скрытых колонок во время перетаскивания. Левая и правая панели сохраняют ширину независимо; прежние настройки переносятся в обе панели.

## [0.1.0] — 2026-11-20

Первая версия.

### Добавлено

- Двухпанельный интерфейс с вкладками и переключением на одну панель (F12).
- Вид «This PC» со списком дисков и свободным местом.
- Сайдбар с папками профиля и дисками.
- Хлебные крошки и ручной ввод пути, история назад/вперёд.
- Сортировка по имени, дате, размеру, типу; фильтр по имени.
- Отметка файлов клавиатурой и мышью.
- Фоновые копирование, перемещение и удаление с прогрессом и отменой.
- Просмотрщик (текст / hex) и встроенный редактор UTF-8.
- Создание файлов и папок, переименование.
- Панель F1–F12 и справка по горячим клавишам.
- Векторные иконки по типу файла и логотип-квокка.
